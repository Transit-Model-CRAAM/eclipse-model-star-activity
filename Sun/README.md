# [🇧🇷 PR BR] Instruções
* O presente path tem como objetivo apoiar os programas ECLIPSE caso seja desejado realizar a análise estelar e do modelo de acordo com um modelo baseado no Sol 
* Existem alguns arquivos presentes em pastas nomeadas como yyy-mm-dd que possuem arquivos .fits com períodos de tempo selecionados para serem utilizados como modelos no ECLIPSE

# [🇺🇸 EN] Instructions
* This path aims to support the ECLIPSE programs if you wish to perform stellar and model analysis according to a model based on the Sun.
* There are some files in folders named yyy-mm-dd that contain .fits files with selected time periods to be used as models in ECLIPSE.
* To download a different time period than those presented here, please download it from the file ```main-sun-lightcurves-sunpy.ipynb```
